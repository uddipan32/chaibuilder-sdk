## Next.js Config — withChaiBuilder

Wrap your `next.config.ts` with `withChaiBuilder` to auto-generate the import map for collections and actions. It also watches for file changes in development.

**Correct:**

```ts
// next.config.ts
import { withChaiBuilder } from "chaicore/next";
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  // your existing config
};

export default withChaiBuilder(nextConfig);
```

**With custom options:**

```ts
export default withChaiBuilder(nextConfig, {
  collections: "src/collections/**/*.{ts,tsx}",           // default
  actions: "src/app/(builder)/**/actions/**/*.{ts,tsx}",  // default
  importMapPath: "src/chaibuilder-import-map.ts",         // default
  watch: true,                                             // default — file watching in dev
});
```

**What it generates (`src/chaibuilder-import-map.ts`):**

```ts
// Auto-generated by @chaibuilder/next — do not edit manually
export const chaibuilderImportMap = {
  collections: {
    BlogPosts: () => import("@/collections/BlogPosts"),
  },
  actions: {
    checkUserAccess: () => import("@/app/(builder)/api/actions/check-user-access"),
  },
} as const;
```

**Rules:**
- Run `withChaiBuilder` once — it wraps the existing `webpack` config safely
- The import map is regenerated on every `next dev` start and on file add/remove
- Collection files: `src/collections/**/*.{ts,tsx}`
- Action files: `src/app/(builder)/**/actions/**/*.{ts,tsx}`
- Both globs can be overridden via options
